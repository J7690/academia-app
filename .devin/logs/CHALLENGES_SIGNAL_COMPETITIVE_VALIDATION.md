## E. Justification Produit

### E.1 Pourquoi le Duel?

**Le duel est le signal compétitif le plus puissant pour 3 raisons:**

1. **Compétition 1v1:** Le duel crée une compétition directe entre deux personnes, ce qui est plus motivant qu'une compétition anonyme (classement global).

2. **Urgence temporelle:** Le duel a souvent une limite de temps (24h), ce qui crée une urgence et une motivation immédiate.

3. **Engagement émotionnel:** Le duel crée un engagement émotionnel (je veux battre cette personne spécifique), ce qui est plus puissant que l'engagement rationnel (je veux monter de rang).

---

### E.2 Pourquoi pas le Signal Dynamique?

**Le signal dynamique est très puissant, mais il a 2 inconvénients:**

1. **Incohérence:** Le signal change selon le contexte, ce qui peut créer de la confusion pour l'utilisateur.

2. **Pas toujours compétitif:** Quand le signal est "Mission", la tension compétitive disparaît, ce qui contredit l'objectif de maximiser la compétition.

**Le duel est plus fiable:** Il est toujours compétitif, toujours motivant, toujours engageant.

---

### E.3 Pourquoi pas le Type de Défi?

**Le type de défi est le signal le plus faible pour 3 raisons:**

1. **Compétition minimale:** Le type de défi n'indique pas une compétition, il indique un contexte.

2. **Motivation faible:** Le type de défi ne crée pas d'urgence ni d'engagement émotionnel.

3. **Différenciation faible:** Le type de défi existe sur d'autres plateformes (ex: YouTube Shorts a des "playlists").

**Le duel est plus différenciant:** Il est unique sur une plateforme académique.

---

### E.4 Impact Attendu

**Adoption:**
- Reconnaissance pattern TikTok (immédiat)
- Identification valeur Academia (compétition)
- Différenciation claire (vs TikTok)

**Engagement:**

- Rétention: +70% (progression, rang, duel)

**ROI:** Très élevé - Tension compétitive maximale + Progression + Différenciation
