# Procédures Détaillées - Windsurf

## Procédure 1: Analyse de Code avec Contexte IDE

### Étapes
1. **Analyser le contexte actuel**
   - Identifier le fichier actif dans l'éditeur
   - Noter la position du curseur
   - Examiner les onglets ouverts
   - Vérifier les erreurs surlignées

2. **Explorer le workspace**
   - Utiliser l'explorateur de fichiers de Windsurf
   - Rechercher avec Ctrl+Shift+F si nécessaire
   - Consulter le panneau des problèmes (Problems)

3. **Analyser les dépendances**
   - Utiliser "Go to Definition" (F12) pour naviguer
   - Utiliser "Find References" (Shift+F12) pour voir l'utilisation
   - Examiner les imports et exports

4. **Fournir l'analyse**
   - Structurer avec des références précises aux lignes
   - Inclure des captures d'écran des erreurs si pertinent
   - Proposer des actions utilisant les capacités de Windsurf

### Check-list
- [ ] Contexte IDE analysé (fichier actif, curseur, onglets)
- [ ] Erreurs et warnings identifiés
- [ ] Dépendances explorées avec navigation
- [ ] Rapport structuré avec références précises

## Procédure 2: Modification de Code Intégrée à Windsurf

### Étapes
1. **Préparation dans l'IDE**
   - Ouvrir tous les fichiers nécessaires dans des onglets
   - Utiliser Split View pour comparer les fichiers
   - Positionner le curseur aux points d'intérêt

2. **Analyse des suggestions**
   - Examiner les suggestions d'IntelliSense
   - Vérifier les quick fixes disponibles (Ctrl+.)
   - Considérer les refactorings suggérés

3. **Exécution des modifications**
   - Utiliser les outils d'édition de Windsurf
   - Appliquer les modifications en utilisant le contexte
   - Profiter du multi-cursor pour les changements répétitifs

4. **Validation en temps réel**
   - Surveiller les erreurs surlignées apparaissant/disparaissant
   - Utiliser le linter intégré pour vérifier la syntaxe
   - Tester avec les outils de débogage si disponible

### Check-list
- [ ] Fichiers ouverts et organisés dans l'IDE
- [ ] Suggestions et quick fixes examinées
- [ ] Modifications appliquées avec outils Windsurf
- [ ] Validation en temps réel effectuée

## Procédure 4: Débogage Avancé dans Windsurf

### Étapes
1. **Configuration du débogueur**
   - Vérifier les fichiers de configuration (.vscode/launch.json)
   - Configurer les points d'arrêt appropriés
   - Paramétrer les variables d'environnement

2. **Session de débogage**
   - Lancer le débogueur avec F5
   - Utiliser les contrôles (step over, step into, continue)
   - Surveiller la fenêtre de variables et la pile d'appels

3. **Analyse des erreurs**
   - Examiner les exceptions levées
   - Consulter les logs dans la console de débogage
   - Utiliser les expressions espionnes (watch)

4. **Correction et validation**
   - Appliquer les corrections pendant la session
   - Tester les corrections immédiatement
   - Documenter les solutions trouvées

### Check-list
- [ ] Débogueur configuré correctement
- [ ] Session de débogage productive
- [ ] Erreurs analysées et comprises
- [ ] Corrections appliquées et validées

## Procédure 5: Recherche et Navigation Intelligente

### Étapes
1. **Recherche rapide**
   - Utiliser Ctrl+P pour Quick Open
   - Rechercher des symboles avec Ctrl+Shift+O
   - Filtrer par type de fichier avec des préfixes (@, #, :)

2. **Recherche avancée**
   - Utiliser Ctrl+Shift+F pour la recherche dans les fichiers
   - Appliquer des filtres et expressions régulières
   - Utiliser les contextes de recherche (inclusions/exclusions)

3. **Navigation efficace**
   - Utiliser Go to Definition (F12)
   - Naviguer avec Peek Definition (Alt+F12)
   - Utiliser Go to Implementation (Ctrl+F12)

4. **Analyse des résultats**
   - Organiser les résultats par pertinence
   - Utiliser les aperçus pour évaluer rapidement
   - Marquer les résultats pertinents

### Check-list
- [ ] Recherche rapide effectuée avec raccourcis
- [ ] Recherche avancée avec filtres appliqués
- [ ] Navigation efficace utilisée
- [ ] Résultats analysés et organisés

## Procédure 6: Refactoring et Optimisation

### Étapes
1. **Identification des opportunités**
   - Analyser le code pour les améliorations possibles
   - Utiliser les suggestions de refactoring de Windsurf
   - Identifier le code dupliqué ou mal structuré

2. **Application des refactorings**
   - Renommer des variables/fonctions (F2)
   - Extraire des méthodes/fonctions
   - Réorganiser la structure du code

3. **Optimisation des performances**
   - Utiliser les outils de profilage si disponibles
   - Optimiser les imports et dépendances
   - Améliorer l'algorithme et la complexité

4. **Validation des changements**
   - Vérifier que le comportement est inchangé
   - Tester les performances améliorées
   - Documenter les modifications

### Check-list
- [ ] Opportunités de refactoring identifiées
- [ ] Refactorings appliqués avec succès
- [ ] Optimisations de performance implémentées
- [ ] Changements validés et documentés
