## 3. TESTS PSYCHOTECHNIQUES — Analyse approfondie

### 3.1 Ce que le Burkina Faso utilise

D'après les recherches, les tests psychotechniques aux concours BF comprennent :

| Type | Description | Concours concernés |
|------|-------------|-------------------|
| **Suites numériques** | Trouver le nombre manquant dans une série logique | Paramilitaire, ENAREF C, Douane |
| **Suites alphabétiques** | Trouver la lettre manquante | Paramilitaire |
| **Suites alphanumériques** | Mélange chiffres + lettres | Tous paramilitaires |
| **Logique verbale** | Analogies, synonymes, antonymes, intrus | Catégories B et C |
| **Logique numérique** | Opérations codées, proportions | ENAREF, Douane |
| **Raisonnement** | Déduction, induction, syllogismes | Tous |
| **Orthographe / Grammaire** | Identifier la faute | Catégories C et D |
| **Conjugaison** | Formes correctes | Catégories C et D |

### 3.2 Standards internationaux des tests psychotechniques

Les tests utilisés au BF suivent les mêmes standards que les concours de la fonction publique française et africaine francophone :

| Catégorie | Types de tests | Standard international |
|-----------|---------------|----------------------|
| **Raisonnement abstrait** | Matrices de Raven (APM), séries graphiques | Raven's Progressive Matrices (Pearson) |
| **Dominos** | D48, D70 — trouver la valeur manquante | Test D48 (Anstey), D70 |
| **Cartes à jouer** | Similaire aux dominos avec des cartes | Concours fonction publique FR |
| **Suites logiques** | Numériques, alphabétiques, graphiques | Universel |
| **Analogies** | Verbales et graphiques | DAT (Differential Aptitude Tests) |
| **Mastermind** | Déduction logique | Spécifique concours FR/Afrique francophone |
| **Attention / Concentration** | Barrage, repérage d'erreurs | Tests de Toulouse-Piéron |

### 3.4 La logique des tests psychotechniques — Guide pour l'IA

Les tests psychotechniques suivent des patterns algorithmiques identifiables :

**1. Suites numériques** : Opérateurs (+n, ×n, ²), suites imbriquées, Fibonacci, alternances
**2. Dominos** : Suites circulaires (0-6), addition/soustraction des faces, symétrie
**3. Matrices de Raven** : Logique de répartition ligne/colonne, rotation, inversion
**4. Analogies** : A est à B ce que C est à ? (transformation identique)
**5. Cartes à jouer** : Même logique que dominos (As=1 → Roi=13)
**6. Séries graphiques** : Rotation, ajout d'élément, symétrie, inversion couleur

**→ L'IA peut générer ces tests car les patterns sont algorithmiques et bien définis.**
