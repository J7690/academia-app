# Raccourcis et Fonctionnalités Windsurf

## Raccourcis Essentiels

### Navigation de Fichiers
- **Ctrl+P**: Quick Open - recherche rapide de fichiers
- **Ctrl+Shift+P**: Command Palette - accès à toutes les commandes
- **Ctrl+Tab**: Basculer entre les onglets ouverts
- **Ctrl+1,2,3...**: Aller à l'onglet numéro N
- **Ctrl+Shift+O**: Aller à un symbole dans le fichier actuel
- **Ctrl+T**: Aller à un symbole dans tout le workspace

### Édition de Code
- **Ctrl+D**: Sélectionner la prochaine occurrence du mot
- **Ctrl+Shift+L**: Sélectionner toutes les occurrences
- **Alt+Up/Down**: Déplacer la ligne vers le haut/bas
- **Shift+Alt+Up/Down**: Copier la ligne vers le haut/bas
- **Ctrl+Shift+K**: Supprimer la ligne actuelle
- **Ctrl+/** : Commenter/décommenter la ligne
- **Shift+Alt+A**: Commenter/décommenter le bloc

### Navigation dans le Code
- **F12**: Go to Definition - aller à la définition
- **Alt+F12**: Peek Definition - voir la définition sans quitter
- **Ctrl+F12**: Go to Implementation - aller à l'implémentation
- **Shift+F12**: Find References - trouver toutes les références
- **Ctrl+G**: Aller à la ligne numéro
- **Ctrl+Home**: Aller au début du fichier
- **Ctrl+End**: Aller à la fin du fichier

### Multi-cursor et Sélection
- **Ctrl+Alt+Up/Down**: Ajouter un curseur au-dessus/en dessous
- **Ctrl+Alt+Click**: Ajouter un curseur à la position du clic
- **Ctrl+U**: Annuler la dernière sélection/curseur
- **Shift+Alt+Drag**: Sélection rectangulaire (column selection)

### Recherche et Remplacement
- **Ctrl+F**: Rechercher dans le fichier actuel
- **Ctrl+H**: Remplacer dans le fichier actuel
- **Ctrl+Shift+F**: Rechercher dans tous les fichiers
- **Ctrl+Shift+H**: Remplacer dans tous les fichiers
- **F3 / Shift+F3**: Suivant/Précédent dans la recherche
- **Ctrl+Shift+J**: Aller à la prochaine correspondance

### Gestion des Fenêtres et Panneaux
- **Ctrl+B**: Basculer la barre latérale (Sidebar)
- **Ctrl+J**: Basculer le panneau inférieur (Panel)
- **Ctrl+`**: Basculer le terminal intégré
- **Ctrl+Shift+`**: Créer un nouveau terminal
- **F11**: Mode plein écran
- **Ctrl+M**: Basculer la minimap
- **Ctrl+Shift+V**: Ouvrir un aperçu Markdown

### Édition Avancée
- **Shift+Alt+F**: Formater le document
- **Ctrl+K, Ctrl+S**: Sauvegarder sans formatage
- **Ctrl+K, Ctrl+F**: Formater la sélection
- **Ctrl+Shift+P**, puis "Format Document With..."

### Débogage
- **F9**: Basculer un point d'arrêt (breakpoint)
- **F5**: Démarrer/Déboguer
- **Ctrl+F5**: Démarrer sans débogage
- **Shift+F5**: Arrêter le débogage
- **F10**: Step Over (exécuter la ligne suivante)
- **F11**: Step Into (entrer dans la fonction)
- **Shift+F11**: Step Out (sortir de la fonction)
- **Ctrl+Shift+F5**: Redémarrer le débogage

### Git et Contrôle de Version
- **Ctrl+Shift+G**: Basculer le panneau Git
- **Alt+Left/Right**: Aller en arrière/avant dans l'historique
- **Ctrl+Enter**: Commit dans le panneau Git
- **Ctrl+Shift+Enter**: Commit et push

### Split View et Éditeurs Multiples
- **Ctrl+\**: Diviser l'éditeur en deux
- **Ctrl+1/2/3**: Focus sur l'éditeur 1/2/3
- **Ctrl+Alt+Flèche**: Déplacer l'éditeur
- **Ctrl+Alt+Flèche+Shift**: Copier l'éditeur

## Fonctionnalités Spéciales à Windsurf

### Intelligence Artificielle Intégrée
- **Tab**: Accepter la suggestion de code IA
- **Ctrl+I**: Demander une suggestion de code
- **Ctrl+Shift+I**: Générer du code à partir d'un commentaire
- **Alt+Enter**: Quick Fix avec suggestions IA

### Commandes de la Palette (Ctrl+Shift+P)
- **"Git: Commit"**: Commit Git rapide
- **"Terminal: Create New Terminal"**: Nouveau terminal
- **"View: Toggle Editor Group Layout"**: Changer la disposition
- **"Workspaces: Add Workspace Folder"**: Ajouter un dossier
- **"File: Save All"**: Sauvegarder tous les fichiers
- **"Editor: Format Document"**: Formater le document

### Extensions Courantes et Leurs Raccourcis

#### Prettier
- **Shift+Alt+F**: Formater avec Prettier
- **Ctrl+Shift+P**, "Format Document"

#### ESLint
- **Ctrl+Shift+P**, "ESLint: Fix all auto-fixable Problems"

#### Python
- **Ctrl+Shift+P**, "Python: Run Python File in Terminal"
- **Ctrl+Shift+P**, "Python: Select Interpreter"

#### Docker
- **Ctrl+Shift+P**, "Docker: Add Docker Files to Workspace"

## Trucs et Astuces

### Productivité
- **Ctrl+Click**: Aller à la définition
- **Alt+Click**: Ajouter un curseur
- **Ctrl+L**: Sélectionner la ligne actuelle
- **Ctrl+Shift+L**: Sélectionner toutes les occurrences de la sélection

### Recherche Intelligente
- **Ctrl+Shift+P**, "@:": Aller aux symboles par catégorie
- **Ctrl+P**, "#": Rechercher dans le contenu des fichiers
- **Ctrl+P**, ">": Accéder aux commandes

### Gestion des Erreurs
- **F8**: Aller à l'erreur suivante
- **Shift+F8**: Aller à l'erreur précédente
- **Ctrl+Shift+M**: Afficher/masquer le panneau des problèmes

### Édition de Texte Avancée
- **Ctrl+Shift+[:** Plier le code
- **Ctrl+Shift+]**: Déplier le code
- **Ctrl+K, Ctrl+0**: Plier tout
- **Ctrl+K, Ctrl+J**: Déplier tout
- **Ctrl+K, Ctrl+1**: Plier niveau 1

## Configuration Recommandée

### settings.json Essentiel
```json
{
    "editor.formatOnSave": true,
    "editor.formatOnPaste": true,
    "editor.suggestSelection": "first",
    "editor.wordWrap": "on",
    "files.autoSave": "afterDelay",
    "files.autoSaveDelay": 1000,
    "workbench.colorTheme": "Default Dark+",
    "workbench.iconTheme": "material-icon-theme",
    "terminal.integrated.shell.windows": "powershell.exe"
}
```

### keybindings.json Personnalisé
```json
[
    {
        "key": "ctrl+;",
        "command": "editor.action.commentLine",
        "when": "editorTextFocus"
    },
    {
        "key": "ctrl+shift+;",
        "command": "editor.action.blockComment",
        "when": "editorTextFocus"
    }
]
```

## Dépannage Commun

### Problèmes de Performance
- **Ctrl+Shift+P**, "Developer: Reload Window"
- **Ctrl+Shift+P**, "Extensions: Disable Extensions"
- Vérifier l'utilisation mémoire avec **Ctrl+Shift+I**

### Raccourcis ne Fonctionnant Pas
- Vérifier les conflits dans **Ctrl+K, Ctrl+S**
- Réinitialiser avec **Ctrl+Shift+P**, "Preferences: Reset Keyboard Shortcuts"

### Extensions ne Répondant Pas
- **Ctrl+Shift+X**: Gérer les extensions
- Redémarrer Windsurf après installation/désinstallation
