# SMART WHITEBOARD USER JOURNEY

**Version** : 1.0  
**Date** : 23 Juin 2026  
**Phase** : UX.1 – Smart Whiteboard User Journey  
**Mode** : ANALYSE  
**Objectif** : Décrire précisément l'expérience utilisateur complète du Smart Whiteboard

---

## CONTEXTE

Le Smart Whiteboard doit devenir :
- Un outil de création de contenu pédagogique
- Plus simple que CapCut
- Inspiré des vidéos GoodNotes
- Compatible TikTok, Facebook, Instagram Reels, YouTube Shorts

**Objectif** : Un étudiant ou un enseignant produit une vidéo pédagogique en moins de 10 minutes.

---

## PARTIE 1 – PARCOURS COMPLET

### 1.1 Étape 1 : Création

**Action** : L'utilisateur ouvre Academia et accède au Smart Whiteboard

**Navigation** :
- Étudiant : Dashboard → Smart Whiteboard
- Enseignant : Dashboard → Smart Whiteboard

**Interface** :
- Bouton "Créer une vidéo pédagogique"
- Sélection du mode de création (Mode A, B, C, D)

**Temps estimé** : 30 secondes

### 1.2 Étape 2 : Génération contenu

**Action** : L'utilisateur fournit l'entrée (sujet, texte, plan, cours)

**Mode A (Sujet uniquement)** :
- Input : "La photosynthèse"
- Bobodo génère : titre, sections, exercices, définitions, storyboard
- Temps estimé : 30 secondes

**Mode B (Texte complet fourni)** :
- Input : Texte complet du cours
- Bobodo génère : storyboard (structuration en scènes et blocs)
- Temps estimé : 20 secondes

**Mode C (Plan fourni)** :
- Input : Plan structuré (I. Introduction, II. Développement, III. Conclusion)
- Bobodo génère : storyboard (détaillage du plan en blocs)
- Temps estimé : 25 secondes

**Mode D (Cours déjà rédigé)** :
- Input : Cours déjà rédigé (copier-coller)
- Bobodo génère : storyboard (structuration en scènes et blocs)
- Temps estimé : 15 secondes

### 1.3 Étape 3 : Correction

**Action** : L'utilisateur corrige le storyboard généré

**Interface** :
- Éditeur de storyboard (drag & drop des blocs)
- Éditeur de texte pour chaque bloc
- Ajout/suppression de blocs
- Réorganisation des scènes

**Actions possibles** :
- Modifier le titre
- Modifier le texte d'un bloc
- Ajouter un bloc
- Supprimer un bloc
- Réorganiser les blocs
- Changer le thème (scientific/notebook)

**Temps estimé** : 2-3 minutes

### 1.4 Étape 4 : Narration

**Action** : L'utilisateur enregistre ou génère la narration

**Option 1 (Utilisateur parle librement)** :
- L'utilisateur enregistre sa voix en temps réel
- Pas de script
- Temps estimé : 2-3 minutes

**Option 2 (Lecture d'un script)** :
- Bobodo génère un script basé sur le storyboard
- L'utilisateur lit le script
- Temps estimé : 2-3 minutes

**Option 3 (Voix IA)** :
- Bobodo génère la narration audio (TTS)
- Temps estimé : 30 secondes

**Option 4 (Mode hybride)** :
- L'utilisateur enregistre sa voix pour certaines parties
- Bobodo génère la voix IA pour d'autres parties
- Temps estimé : 2-3 minutes

**Recommandation V1** : Option 2 (Lecture d'un script)

### 1.5 Étape 5 : Prévisualisation

**Action** : L'utilisateur prévisualise la vidéo

**Interface** :
- Lecteur vidéo (vertical TikTok)
- Contrôles : play/pause, seek, volume
- Bouton "Régénérer" (si non satisfait)
- Bouton "Modifier" (retour à l'étape 3)

**Temps estimé** : 30 secondes

### 1.6 Étape 6 : Export

**Action** : L'utilisateur exporte la vidéo

**Options** :
- Format : MP4 (1080x1920)
- Qualité : Haute (H.264, CRF 23)
- Durée : Variable (10-60 secondes)

**Temps estimé** : 30 secondes

### 1.7 Étape 7 : Publication

**Action** : L'utilisateur publie la vidéo

**Options** :
- TikTok (intégration directe)
- Facebook (intégration directe)
- Instagram Reels (intégration directe)
- YouTube Shorts (intégration directe)
- Téléchargement (MP4 local)

**Interface** :
- Sélection de la plateforme
- Ajout de caption
- Ajout de hashtags
- Sélection de la visibilité (public/amis/privé)
- Bouton "Publier"

**Temps estimé** : 1 minute

### 1.8 Temps total estimé

**Mode A (Sujet uniquement)** : 30s + 30s + 2-3min + 2-3min + 30s + 30s + 1min = **7-8 minutes**  
**Mode B (Texte complet fourni)** : 30s + 20s + 2-3min + 2-3min + 30s + 30s + 1min = **7-8 minutes**  
**Mode C (Plan fourni)** : 30s + 25s + 2-3min + 2-3min + 30s + 30s + 1min = **7-8 minutes**  
**Mode D (Cours déjà rédigé)** : 30s + 15s + 2-3min + 2-3min + 30s + 30s + 1min = **7-8 minutes**

**Conclusion** : L'objectif de moins de 10 minutes est atteint.

## PARTIE 2 – MODES DE CRÉATION

### 2.1 Mode A : Sujet uniquement

**Input** : Sujet simple (ex: "La photosynthèse")

**Processus** :
1. L'utilisateur entre le sujet
2. Bobodo génère le contenu complet :
   - Titre
   - Sections
   - Exercices
   - Définitions
   - Storyboard
3. L'utilisateur corrige le storyboard

**Avantages** :
- Plus simple pour les débutants
- Bobodo fait tout le travail
- Idéal pour les sujets connus

**Inconvénients** :
- Moins de contrôle sur le contenu
- Dépendance à Bobodo

**Temps estimé** : 7-8 minutes

### 2.2 Mode B : Texte complet fourni

**Input** : Texte complet du cours (ex: copier-coller depuis un PDF)

**Processus** :
1. L'utilisateur colle le texte complet
2. Bobodo génère le storyboard (structuration en scènes et blocs)
3. L'utilisateur corrige le storyboard

**Avantages** :
- Contrôle total sur le contenu
- Bobodo fait la structuration
- Idéal pour les cours déjà rédigés

**Inconvénients** :
- Nécessite d'avoir le texte complet
- Plus long à coller le texte

**Temps estimé** : 7-8 minutes

### 2.3 Mode C : Plan fourni

**Input** : Plan structuré (ex: I. Introduction, II. Développement, III. Conclusion)

**Processus** :
1. L'utilisateur entre le plan
2. Bobodo génère le storyboard (détaillage du plan en blocs)
3. L'utilisateur corrige le storyboard

**Avantages** :
- Contrôle sur la structure
- Bobodo fait le détaillage
- Idéal pour les enseignants qui ont un plan

**Inconvénients** :
- Nécessite d'avoir un plan
- Moins flexible que le mode B

**Temps estimé** : 7-8 minutes

### 2.4 Mode D : Cours déjà rédigé

**Input** : Cours déjà rédigé (ex: copier-coller depuis Word)

**Processus** :
1. L'utilisateur colle le cours
2. Bobodo génère le storyboard (structuration en scènes et blocs)
3. L'utilisateur corrige le storyboard

**Avantages** :
- Plus rapide (cours déjà rédigé)
- Contrôle total sur le contenu
- Idéal pour les enseignants

**Inconvénients** :
- Nécessite d'avoir le cours déjà rédigé
- Similaire au mode B

**Temps estimé** : 7-8 minutes

## PARTIE 3 – RÔLE DE BOBODO

### 3.1 Ce que génère Bobodo

**Mode A (Sujet uniquement)** :
- **Titre** : Titre accrocheur basé sur le sujet
- **Sections** : 3-5 sections logiques
- **Exercices** : 2-3 exercices avec corrections
- **Définitions** : 2-3 définitions clés
- **Storyboard** : Structuration en scènes et blocs

**Mode B (Texte complet fourni)** :
- **Storyboard** : Structuration du texte en scènes et blocs

**Mode C (Plan fourni)** :
- **Storyboard** : Détaillage du plan en blocs

**Mode D (Cours déjà rédigé)** :
- **Storyboard** : Structuration du cours en scènes et blocs

### 3.2 Détail de la génération

**Titre** :
- Basé sur le sujet
- Accrocheur (ex: "Comprendre la photosynthèse en 60 secondes")
- Optimisé pour TikTok (court, percutant)

**Sections** :
- 3-5 sections logiques
- Chaque section correspond à une scène
- Exemple : Introduction, Définition, Processus, Importance, Conclusion

**Exercices** :
- 2-3 exercices avec corrections
- Exercices simples (QCM, vrai/faux)
- Corrections détaillées

**Définitions** :
- 2-3 définitions clés
- Définitions claires et concises
- Exemples si nécessaire

**Storyboard** :
- Structuration en scènes (3-5 scènes)
- Chaque scène contient 2-5 blocs
- Blocs : title, paragraph, formula, definition, exercise, correction
- Animation : fade_in
- Thème : scientific ou notebook

### 3.3 Qualité de la génération

**Bobodo utilise** :
- LLM (OpenRouter) pour la génération de contenu
- RAG (si documents pertinents disponibles)
- Prompt système optimisé pour le contenu pédagogique
- Validation du Data Contract Smart Whiteboard

**Qualité attendue** :
- Contenu pédagogique de qualité
- Structuration logique
- Exercices pertinents
- Définitions précises

## PARTIE 4 – NARRATION

### 4.1 Option 1 : Utilisateur parle librement

**Description** : L'utilisateur enregistre sa voix en temps réel

**Processus** :
1. L'utilisateur clique sur "Enregistrer"
2. L'utilisateur parle librement
3. L'utilisateur clique sur "Arrêter"
4. L'utilisateur prévisualise
5. L'utilisateur valide ou réenregistre

**Avantages** :
- Naturel
- Flexibilité
- Pas de script

**Inconvénients** :
- Risque d'erreurs
- Temps de préparation
- Nécessite un bon micro

**Temps estimé** : 2-3 minutes

### 4.2 Option 2 : Lecture d'un script

**Description** : Bobodo génère un script basé sur le storyboard, l'utilisateur lit le script

**Processus** :
1. Bobodo génère le script
2. L'utilisateur lit le script
3. L'utilisateur enregistre sa voix
4. L'utilisateur prévisualise
5. L'utilisateur valide ou réenregistre

**Avantages** :
- Script structuré
- Moins d'erreurs
- Meilleure qualité

**Inconvénients** :
- Moins naturel
- Temps de préparation
- Nécessite un bon micro

**Temps estimé** : 2-3 minutes

### 4.3 Option 3 : Voix IA

**Description** : Bobodo génère la narration audio (TTS)

**Processus** :
1. Bobodo génère le script
2. Bobodo génère l'audio (TTS)
3. L'utilisateur prévisualise
4. L'utilisateur valide ou régénère

**Avantages** :
- Rapide
- Pas de micro nécessaire
- Qualité constante

**Inconvénients** :
- Moins naturel
- Voix robotique
- Coût (crédits)

**Temps estimé** : 30 secondes

### 4.4 Option 4 : Mode hybride

**Description** : L'utilisateur enregistre sa voix pour certaines parties, Bobodo génère la voix IA pour d'autres parties

**Processus** :
1. L'utilisateur sélectionne les parties à enregistrer
2. L'utilisateur enregistre sa voix
3. Bobodo génère la voix IA pour les autres parties
4. L'utilisateur prévisualise
5. L'utilisateur valide ou modifie

**Avantages** :
- Flexibilité
- Qualité variable
- Rapide pour certaines parties

**Inconvénients** :
- Complexe
- Cohérence difficile
- Temps de préparation

**Temps estimé** : 2-3 minutes

### 4.5 Recommandation V1

**Option recommandée** : Option 2 (Lecture d'un script)

**Justification** :
- Meilleure qualité que l'option 1
- Plus naturel que l'option 3
- Plus simple que l'option 4
- Compatible avec l'objectif de moins de 10 minutes

**Implémentation V1** :
- Bobodo génère le script
- L'utilisateur lit le script
- L'utilisateur enregistre sa voix
- Synchronisation mot à mot (optionnelle, reportée en V2)

## PARTIE 6 – DIFFÉRENTIATION ACADEMIA

### 6.1 Academia vs CapCut

**CapCut** :
- Outil d'édition vidéo généraliste
- Courbe d'apprentissage élevée
- Nécessite des compétences en montage
- Pas de génération de contenu pédagogique
- Pas de structuration automatique

**Academia** :
- Outil spécialisé contenu pédagogique
- Courbe d'apprentissage faible
- Aucune compétence en montage requise
- Génération de contenu pédagogique par Bobodo
- Structuration automatique par Bobodo

**Différenciation clé** : Academia est spécialisé, CapCut est généraliste.

### 6.2 Academia vs Canva

**Canva** :
- Outil de design graphique
- Pas de génération de vidéo pédagogique
- Pas de structuration automatique
- Pas de narration audio
- Courbe d'apprentissage moyenne

**Academia** :
- Outil de création de vidéo pédagogique
- Génération de contenu pédagogique par Bobodo
- Structuration automatique par Bobodo
- Narration audio (script + enregistrement)
- Courbe d'apprentissage faible

**Différenciation clé** : Academia génère du contenu pédagogique, Canva ne fait que du design.

### 6.3 Academia vs TikTok

**TikTok** :
- Plateforme de partage de vidéo
- Pas de création de contenu pédagogique
- Pas de structuration automatique
- Pas de narration audio
- Courbe d'apprentissage moyenne

**Academia** :
- Outil de création de contenu pédagogique
- Génération de contenu pédagogique par Bobodo
- Structuration automatique par Bobodo
- Narration audio (script + enregistrement)
- Publication directe sur TikTok

**Différenciation clé** : Academia crée du contenu pédagogique, TikTok partage du contenu.

## PARTIE 7 – QUESTION FINALE

### 7.1 Pourquoi utiliser Smart Whiteboard plutôt que CapCut ?

**Réponse** : Parce que Smart Whiteboard est spécialisé dans la création de contenu pédagogique, alors que CapCut est un outil d'édition vidéo généraliste.

**Détails** :

**1. Spécialisation pédagogique**
- Smart Whiteboard : Génère du contenu pédagogique (exercices, définitions, sections)
- CapCut : Ne génère pas de contenu pédagogique

**2. Structuration automatique**
- Smart Whiteboard : Bobodo structure automatiquement le contenu en scènes et blocs
- CapCut : L'utilisateur doit structurer manuellement

**3. Courbe d'apprentissage**
- Smart Whiteboard : Faible (moins de 10 minutes pour créer une vidéo)
- CapCut : Élevée (nécessite des compétences en montage)

**4. Génération de script**
- Smart Whiteboard : Bobodo génère un script pour la narration
- CapCut : L'utilisateur doit écrire son propre script

**5. Intégration pédagogique**
- Smart Whiteboard : Intégré à l'écosystème Academia (prépa concours, TD, quiz)
- CapCut : Pas d'intégration pédagogique

**6. Publication multi-plateforme**
- Smart Whiteboard : Publication directe sur TikTok, Facebook, Instagram Reels, YouTube Shorts
- CapCut : Publication manuelle sur chaque plateforme

**7. Coût**
- Smart Whiteboard : Crédits Academia (système de crédits existant)
- CapCut : Gratuit (mais avec limitations)

**Conclusion** : Smart Whiteboard est le choix optimal pour les créateurs de contenu pédagogique qui veulent créer des vidéos rapidement et facilement, sans compétences en montage.
