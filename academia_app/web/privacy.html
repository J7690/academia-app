Politique de confidentialite - Academia

Derniere mise a jour : 2 juin 2026

Academia est une application educative editee par Nexiom Group. La presente politique decrit comment nous collectons, utilisons et protegeons vos donnees personnelles.

1. Donnees collectees

Nous collectons les categories de donnees suivantes :

  • Informations de compte : nom, prenom, adresse e-mail, mot de passe (chiffre), numero de telephone (optionnel), photo de profil ;
  • Donnees de profil etudiant : etablissement, filiere, niveau d'etudes, ville, pays ;
  • Contenu genere par l'utilisateur (UGC) : messages dans les communautes, commentaires video, posts dans les forums de cours, messages prives (DM), videos publiees ;
  • Donnees de navigation : ecrans visites, onglets consultes, duree de consultation (anonymisees et agregees pour ameliorer le service) ;
  • Donnees de paiement : historique de transactions via LigdiCash (nous ne stockons pas les informations de carte bancaire) ;
  • Donnees techniques : type d'appareil, version du systeme d'exploitation, tokens FCM pour les notifications push ;
  • Donnees IA : messages envoyes au tuteur IA, questions generees, corrections automatiques (pour ameliorer la qualite des reponses).

2. Finalites du traitement

  • Fournir les services educatifs (cours en ligne, preparation concours, travaux diriges, challenges video) ;
  • Permettre la communication entre utilisateurs (communautes, DM, forums) ;
  • Assurer la moderation du contenu (signalement, blocage, filtrage automatique de mots interdits) ;
  • Fournir des reponses personnalisees via l'intelligence artificielle (tuteur IA) ;
  • Gerer les paiements et abonnements ;
  • Envoyer des notifications push pertinentes (nouveaux cours, messages, rappels) ;
  • Analyser l'utilisation du service pour ameliorer l'experience utilisateur ;
  • Diffuser des sessions de cours en direct (live streaming via LiveKit) ;
  • Permettre le fonctionnement du marketplace (annonces, commandes).

3. Intelligence artificielle

Academia utilise des modeles d'IA generative (via OpenRouter) pour :

  • Le tuteur IA de preparation aux concours ;
  • La generation de QCM et exercices ;
  • La correction automatique de devoirs ;
  • L'analyse de documents scannes.

Les messages envoyes a l'IA sont traites par des prestataires tiers (OpenRouter, Google Gemini) conformement a leurs politiques de confidentialite respectives. Nous ne vendons pas ces donnees.

4. Moderation et securite

  • Les contenus publies sont soumis a un filtrage automatique (mots interdits) ;
  • Les utilisateurs peuvent signaler tout contenu inapproprie ou tout utilisateur ;
  • Les utilisateurs peuvent bloquer ou mettre en sourdine d'autres utilisateurs ;
  • L'administrateur peut suspendre des comptes en cas de violation des regles communautaires ;
  • Les signalements sont revus par notre equipe de moderation.

5. Partage avec des tiers

Vos donnees sont partagees uniquement avec :

  • Supabase (hebergement base de donnees et authentification) ;
  • Firebase / Google Cloud (notifications push, analytics) ;
  • OpenRouter (traitement IA - uniquement les messages envoyes au tuteur) ;
  • LiveKit (sessions live streaming) ;
  • LigdiCash (traitement des paiements mobile money).

Nous ne vendons jamais vos donnees personnelles a des tiers.

6. Duree de conservation

  • Donnees de compte : conservees tant que le compte est actif ;
  • Compte supprime : donnees purgees automatiquement apres 60 jours ;
  • Messages et contenus : conserves tant que le compte existe (sauf suppression manuelle par l'utilisateur) ;
  • Donnees de navigation/analytics : conservees 12 mois puis anonymisees ;
  • Logs techniques : conserves 90 jours.

7. Vos droits

Conformement a la reglementation applicable, vous disposez des droits suivants :

  • Acces : consulter vos donnees personnelles ;
  • Rectification : modifier vos informations depuis l'application ;
  • Suppression : supprimer votre compte depuis Parametres > Supprimer mon compte ;
  • Opposition : desactiver les notifications push, refuser le tracking ;
  • Portabilite : demander une copie de vos donnees en contactant support@nexiomgroup.space.

8. Permissions de l'application

  • Camera : enregistrement de videos pour les challenges educatifs ;
  • Microphone : enregistrement audio pour les messages vocaux et les videos ;
  • Stockage : telechargement de videos et documents ;
  • Notifications : recevoir des alertes sur les nouveaux cours et messages ;
  • Internet : fonctionnement general de l'application.

9. Securite

Nous mettons en oeuvre des mesures de securite appropriees :

  • Chiffrement des communications (HTTPS/TLS) ;
  • Mots de passe haches (bcrypt via Supabase Auth) ;
  • Tokens d'authentification JWT avec expiration ;
  • Acces aux donnees restreint par Row Level Security (RLS).

10. Enfants

Academia est destinee aux etudiants de l'enseignement superieur et aux professionnels. L'application n'est pas destinee aux enfants de moins de 13 ans. Si nous decouvrons qu'un enfant de moins de 13 ans a cree un compte, nous le supprimerons.

11. Modifications

Cette politique peut etre mise a jour periodiquement. La version en vigueur est celle publiee sur cette page. Les modifications significatives seront notifiees via l'application.
