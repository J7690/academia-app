## 1. LE SYSTÈME DES CONCOURS AU BURKINA FASO

### 1.1 Organisation institutionnelle

| Institution | Rôle |
|-------------|------|
| **Ministère de la Fonction Publique** (fonction-publique.gov.bf) | Organise les concours directs et professionnels |

### 1.3 Format des épreuves (session 2025 — 101 concours, ~2M candidatures, 5 046 postes)

| Type d'épreuve | Format | Concours concernés |
|----------------|--------|-------------------|

| **QCM Économie / Finances publiques** | Macro/microéconomie, fiscalité, budget de l'État | ENAREF, administration économique |
| **QCM Connaissances professionnelles** | Spécifique au corps de métier | Chaque concours a son programme |

| **Français** | Grammaire, conjugaison, orthographe, compréhension | Catégories B, C, D |

### 2.2 Opportunité massive pour Academia

**Constat** : Il n'existe **AUCUNE application mobile native** avec IA pour la préparation aux concours de la fonction publique au Burkina Faso.

| Ce que les concurrents font | Ce qu'Academia peut faire de PLUS |
|---|---|
| QCM statiques en PDF/web | QCM adaptatifs avec IA qui génère des questions variées depuis les vrais sujets |
| Corrections textuelles basiques | IA tuteur qui explique pas à pas, corrige avec bienveillance, cite les sources |
| Aucune personnalisation | Parcours adapté au niveau, aux faiblesses, au concours ciblé |
| Pas de gamification | XP, streaks, badges, classement, défis quotidiens |
| Pas de communauté | Chat communautaire entre candidats, entraide |
| Pas d'app mobile | App Flutter native Android (principal device au BF) |
| ~2 millions de candidatures/an | Marché gigantesque, quasi-vierge en numérique |

## 3. ARCHITECTURE CIBLE — Pipeline IA avec sujets réels

### 3.1 Flux complet

```
┌──────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 1 — INGESTION (Admin Academia)                               │
│                                                                      │
│  Admin upload un PDF de sujet réel (ex: "QCM Culture Générale       │
│  Concours directs 2024, toutes catégories")                         │
│       ↓                                                              │
│  [Supabase Storage: prep-documents]                                  │
│       ↓                                                              │
│  [Edge Function: prep-ingest-document]                               │
│    1. Télécharge le PDF                                              │
│    2. Extraction texte via OpenRouter (pdf-text = GRATUIT)           │
│       ou Mistral OCR ($2/1000 pages) pour les scans                  │
│    3. Découpage intelligent :                                        │
│       - Détecte chaque question (Q1, Q2... ou 1., 2., a), b)...)    │
│       - Sépare question / options / correction si disponible         │
│    4. Génère des embeddings (text-embedding-3-small via OpenRouter)  │
│    5. Stocke dans prep_doc_chunks + pgvector                        │
│    6. Status → "indexed"                                             │
└──────────────────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 2 — GÉNÉRATION IA DE QUESTIONS                               │
│                                                                      │
│  [Edge Function: prep-generate-questions]                            │
│                                                                      │
│  Mode A — "Questions similaires" :                                   │
│    "Voici un sujet réel ENAREF 2023. Génère 10 nouvelles questions  │
│     du MÊME type, MÊME difficulté, MÊME domaine, mais avec des      │
│     données/situations différentes. Fournis la correction détaillée."│
│                                                                      │
│  Mode B — "Examen blanc" :                                           │
│    "Compose un examen blanc complet de 40 QCM pour le concours      │
│     d'Administrateur Civil, en t'inspirant des sujets réels         │
│     2020-2024. Mélange culture générale (15), droit (10),           │
│     économie (10), actualités BF (5)."                               │
│                                                                      │
│  Mode C — "Révision ciblée" :                                        │
│    "L'étudiant a 45% en droit administratif. Génère 10 questions    │
│     progressives (facile → difficile) sur les points faibles        │
│     identifiés, en t'appuyant sur les vrais sujets."                │
└──────────────────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 3 — TUTEUR IA CONTEXTUEL (Étudiant)                          │
│                                                                      │
│  Étudiant : "Je ne comprends pas pourquoi c'est la réponse B        │
│  à la question sur les attributions du Premier Ministre."            │
│       ↓                                                              │
│  [Edge Function: prep-tutor-chat v2]                                 │
│    1. Recherche sémantique → trouve les chunks pertinents            │
│       (Constitution BF, cours de droit constitutionnel indexés)      │
│    2. Prompt enrichi :                                               │
│       "Contexte: Article 46 de la Constitution du Burkina Faso...    │
│        Sujet réel ENAREF 2023, question 15..."                       │
│    3. L'IA répond avec :                                             │
│       ✅ L'explication détaillée                                     │
│       📚 La référence au texte de loi / sujet source                │
│       💡 Un conseil de mémorisation                                  │
│       🔗 "Cette question est similaire à Q23 du concours 2021"      │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.2 Ce qui utilise les crédits OpenRouter (mêmes que Bobodo)

| Opération | Modèle recommandé | Coût | Quand |
|-----------|-------------------|------|-------|
| **Extraction PDF** (pdf-text) | Intégré OpenRouter | **GRATUIT** | À l'upload d'un document |
| **Extraction PDF scanné** (mistral-ocr) | Mistral OCR | $2/1000 pages | Seulement si le PDF est un scan image |
| **Embeddings** | text-embedding-3-small | $0.02/1M tokens | À l'indexation d'un document |
| **Génération QCM** | Claude 3.5 Sonnet / GPT-4o-mini | ~$0.01-0.03/question | Admin génère ou automatique |
| **Chat tuteur** | Claude 3.5 Haiku / Gemini Flash | ~$0.001-0.005/message | Chaque message étudiant |

**Estimation pour 100 sujets + 1000 questions générées + 5000 messages tuteur/mois : ~$15-30/mois** (avec les mêmes crédits que Bobodo).

### 4.1 Supabase — Nouvelles structures

#### A. Activer pgvector + enrichir les chunks
```sql
CREATE EXTENSION IF NOT EXISTS vector;

ALTER TABLE app.prep_doc_chunks 
  ADD COLUMN IF NOT EXISTS embedding vector(1536),
  ADD COLUMN IF NOT EXISTS chunk_type TEXT DEFAULT 'content',
  ADD COLUMN IF NOT EXISTS concours_type TEXT,
  ADD COLUMN IF NOT EXISTS subject_name TEXT,
  ADD COLUMN IF NOT EXISTS year TEXT,
  ADD COLUMN IF NOT EXISTS question_number INTEGER,
  ADD COLUMN IF NOT EXISTS is_correction BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS token_count INTEGER;

CREATE INDEX IF NOT EXISTS idx_prep_chunks_embedding 
  ON app.prep_doc_chunks USING ivfflat (embedding vector_cosine_ops);
```

#### B. Enrichir prep_source_documents
```sql
ALTER TABLE app.prep_source_documents 
  ADD COLUMN IF NOT EXISTS concours_type TEXT,
  ADD COLUMN IF NOT EXISTS subject_name TEXT,
  ADD COLUMN IF NOT EXISTS original_filename TEXT,
  ADD COLUMN IF NOT EXISTS page_count INTEGER,
  ADD COLUMN IF NOT EXISTS extraction_method TEXT DEFAULT 'pdf-text',
  ADD COLUMN IF NOT EXISTS has_correction BOOLEAN DEFAULT false;
```

```sql

  p_query_embedding vector(1536),
  p_subject_id UUID DEFAULT NULL,
  p_concours_type TEXT DEFAULT NULL,
  p_limit INTEGER DEFAULT 10
) RETURNS JSONB ...
```

```sql
CREATE TABLE IF NOT EXISTS app.prep_ai_corrections (
```

## 6. PLAN D'IMPLÉMENTATION PAR PHASES

### Phase 1 : Adaptation Burkina Faso + Infrastructure (2 jours)

**Jour 1 — SQL + Données de base**
- Activer pgvector sur Supabase
- Ajouter colonnes embedding + métadonnées aux tables
- Créer la fonction de recherche sémantique
- Insérer les 14 concours BF + 19 matières comme seed data
- Créer la table `prep_ai_corrections`

**Jour 2 — Flutter : remplacement Cameroun → BF**
- Mettre à jour `prep_quiz_tab.dart` : grille concours BF
- Mettre à jour `prep_subjects_tab.dart` : matières BF
- Mettre à jour `teacher_prep_screen.dart` : dropdowns BF
- Mettre à jour `prep-tutor-chat` Edge Function : system prompt BF
- Mettre à jour `prep_quiz_provider.dart` : questions démo BF
- Seed : 50 questions de culture générale BF pour que l'app soit fonctionnelle immédiatement

### Phase 2 : Edge Function d'ingestion de PDF (2 jours)

**`prep-ingest-document`** (Deno, Supabase Edge Function)
- Input : document_id (déjà uploadé dans Storage)
- Télécharge le PDF depuis Supabase Storage
- Envoie à OpenRouter (`pdf-text` gratuit, `mistral-ocr` si scan)
- Parse le texte : détecte les questions, les options, les corrections
- Découpe en chunks sémantiques (1 chunk = 1 question + options + correction)
- Génère des embeddings via OpenRouter (text-embedding-3-small)
- Stocke chunks + embeddings dans `prep_doc_chunks`
- Met à jour `prep_source_documents.status = 'indexed'`

### Phase 3 : Edge Function de génération de questions (2 jours)

**`prep-generate-questions`** (Deno, Supabase Edge Function)
- Input : concours_type, subject_name, count, mode (similaire/examen_blanc/revision)
- Recherche sémantique dans `prep_doc_chunks` pour trouver les sujets réels pertinents
- Construit un prompt spécialisé avec le contexte des vrais sujets
- Appelle OpenRouter (Claude Sonnet / GPT-4o-mini)
- Parse le JSON retourné
- Insère dans `prep_questions` + `prep_question_choices` (status = 'proposed')
- L'admin valide → 'published' → visible par les étudiants

### Phase 4 : Tuteur IA v2 avec RAG (1 jour)

**Amélioration de `prep-tutor-chat`**
- Quand l'étudiant pose une question :
  1. Génère un embedding de la question
  2. Recherche sémantique dans `prep_doc_chunks`
  3. Injecte les chunks pertinents dans le prompt système
  4. L'IA répond avec contexte réel et cite ses sources
- Nouveau mode "Correction" :
  - L'étudiant propose une réponse
  - L'IA dit si c'est correct/incorrect
  - Fournit l'explication avec référence au texte de loi / sujet source
  - Sauvegarde dans `prep_ai_corrections`

### Phase 5 : UI Admin d'ingestion (1 jour)

- Écran upload PDF avec métadonnées (concours BF, matière, année, catégorie)
- Barre de progression : upload → extraction → indexation
- Liste des documents indexés avec statut
- Bouton "Générer QCM depuis ce sujet" avec paramètres
- Review des questions générées : éditer, valider, supprimer

### Phase 6 : UI Étudiant enrichie (1 jour)

- Sélection du concours cible (ENAREF B, Administrateur Civil, etc.)
- Quiz adapté au concours choisi
- Le tuteur IA cite ses sources
- Historique des corrections IA personnalisées
- Badge "Sujet réel" sur les questions issues de vrais concours

**Total : 9 jours de développement**
